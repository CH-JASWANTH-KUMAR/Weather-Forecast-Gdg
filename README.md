# Weather GDG Project 🌤️

This is a **Python project** built for the **Google Developer Group (GDG) application**.  
It uses the **OpenWeatherMap API** to fetch real-time weather data for any city and performs a simple but insightful analysis.

---

## Features
- Fetch **current weather** including:
  - Temperature 🌡
  - Feels Like 🌬
  - Humidity 💧
  - Wind Speed 🌪
  - Weather Condition ☁️
- Fetch **5-day forecast** and calculate **daily average temperature** 📅
- Perform **trend analysis**:
  - Detect if temperatures are **Rising**, **Falling**, or **Stable** 🔍
- Analyze **comfort level** (Hot, Pleasant, Cold) and **humidity level** (Humid, Comfortable)
- Simple, user-friendly **command-line interface**
- Ready for enhancement: can add **graphs, favorites, or unit toggle**

---

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/weather-gdg.git
   ```
2. Navigate to the project folder:
   ```bash
   cd weather-gdg
   ```
3. Install dependencies:
   ```bash
   pip install requests
   ```
4. Run the script:
   ```bash
   python WeatherGdg.py
   ```
